Features

On-Chain Governance

Container scheduling decisions are recorded on FEVM. Member registration, image assignments, and status reports are all verifiable on-chain.

libp2p Mesh

Nodes discover each other via mDNS and bootstrap, communicate over encrypted TCP channels, and maintain cluster state through GossipSub heartbeats.

Container Orchestration

Automatic image pulling, port detection, health checks, restart policies, and resource limits (CPU/memory). Zero-downtime image swaps.

IPFS Persistence

Container metadata and image manifests are pinned to IPFS via Pinata, creating an immutable audit trail of every deployment.
